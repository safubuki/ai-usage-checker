# 認証・利用枠更新とカード並べ替えの回帰検証

追加のテスト用 NuGet パッケージなしで動くコンソールテストです。

```powershell
dotnet run --project tests/AIUsageChecker.RegressionTests/AIUsageChecker.RegressionTests.csproj
```

全AIの個別再取得、認証復帰、通信失敗からの復帰、全体更新との競合を検証します。
GrokはHTTP 401/403、トークン更新、認証ファイルの再読込、過去ログへのフォールバックを検証します。
Claudeは認証情報の欠落・不正な形式、未契約の判定、認証情報の再読込を検証します。
契約判定は、設定ファイルが古くてもCLI (`claude auth status`) の契約種別で契約中と判定すること、CLIの未ログインを優先すること、CLI・設定ファイルとも有料プランなしの場合だけ未契約とすること、CLIの結果が不正な場合は設定ファイルで判定することを検証します。CLIは偽の出力に置き換えます。GPT・Copilot・Grokは無料プランを未契約とし、利用枠は表示することを検証します。
詳細画面は全AIの認証ボタンと案内の表示条件、操作中の無効化、ボタンの寸法・文言を検証します。
カード操作はクリックとドラッグの判定、左右ボタンの除外、前方・後方・段を跨ぐ移動、末尾への移動、取消・画面外ドロップ、順序保存の呼び出しを検証します。
CLI更新通知は1件からの表示、表示済み履歴の保存と再起動後の再案内抑制、新バージョン・別CLIの案内、読み込み・詳細画面中の非表示、カード寸法の維持、上下段の更新バッジとの重なり、既存のCLI更新ボタンとの配色の一致を検証します。一括更新は偽のCLI処理で順次実行、失敗後の続行、同期や二重操作との競合を検証します。
手動再表示は右クリックメニューとショートカットの接続、案内済み更新の再表示、履歴の保持と自動通知の抑制、更新対象なし・操作中の扱いを検証します。
未契約のClaudeにCLI更新がある場合は、「更新あり」を優先して通知・一括更新に含め、更新完了後に「未契約」に戻すことを検証します。更新失敗時は「更新あり」を維持し、契約状況はカード本文に残します。未ログイン・取得エラー・更新中のCLIは対象から除外します。
CLI更新がすべて成功した結果はグリーン系、一部・全部が失敗した結果はオレンジ系を維持することを検証します。カードと詳細画面のCLI状態バッジは、全8状態で文字が帯の縦中央に配置され、カードの寸法・位置が変わらないことを確認します。
リセット日時は当日と翌日の区別、月末・年末、UTC・オフセット付き日時からローカルへの変換、小数秒付きのISO日時の整形を検証します。日時以外の文字列からリセット日を推測しないことも確認します。GPT・Claude・Geminiの実際の読込処理も偽データで検証し、日付表示によるカード寸法の変化と日付・時刻の省略を確認します。

利用枠クライアントとHTTPを偽応答に置き換え、キャッシュ・認証・ログはテスト専用の一時ディレクトリ内で作成して終了時に削除します。実際のユーザー認証ファイル、ネットワーク、CLIは使用しません。
UIは共通のSTA内で表示せずに配置し、ドラッグ処理も偽応答に置き換えます。MainWindowのXAMLはイベントを除いた通常のWindowとして読み込み、実際のMainWindowやユーザー設定を生成せずに配置を検証します。既存の順序保存経路への呼び出しはテスト用コールバックで検証します。
失敗したケースがある場合は終了コード1を返します。
